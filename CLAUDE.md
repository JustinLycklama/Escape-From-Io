# Escape From Io

Indirect-control RTS in Unity. **Target is PC only (Windows, mouse + keyboard).** The game was originally mobile-first.
Ignore the touch/joystick/mobile code: don't extend it, don't design around it, and don't spend effort on Android/iOS. The player queues tasks (mine, build, haul) and robots with limited battery pull work from per-type queues.
The goal is to build an escape shuttle before you run out of robots. The repo folder is named "Pathfinding" for historical reasons.

**Read `ARCHITECTURE.md` before non-trivial changes.** It covers systems, coordinate spaces, the task pipeline and known issues.

## Environment

- **Unity 6000.3.28f1 LTS** on the built-in render pipeline. It was upgraded from 2019.2.9f1 (v0.2) in Nov 2026; see ARCHITECTURE.md → Unity 6 upgrade.
- `*.csproj`/`*.sln` are generated by Unity and gitignored, so never edit them.
- Windows dev machine, PowerShell. In PowerShell, refresh PATH or use the full path if `unity` isn't found.
  Set `UNITY_NO_BANNER=1` and `UNITY_NO_PAGER=1` for clean output.

## Driving the editor: Unity CLI

The Unity CLI (`unity`, installed via winget) drives the editor through the `com.unity.pipeline` package. There is no MCP server.
The editor must be open: run `unity open .` from the repo root, then `unity status` should show the project as `ready`.

- `unity recompile`: compile and list errors (an empty table means clean)
- `unity command console get --level warn --tail 50` / `console clear`: read or clear the console
- `unity command scene open --path Scenes/GameScene`
- `unity command editor.playmode start` / `stop` / `pause`
- `unity command capture game_view --output-path Screenshots/x.png`: screenshot (Screenshots/ is gitignored)
- `unity command scene get_hierarchy`, `unity command gameobject …`, `unity test`
- `unity command` lists the command groups and `unity command <group>` lists a group's commands. Check these before guessing flags.

To verify a change: recompile, clear the console, start play mode, wait, read the console at warn level, capture the game view, then stop play mode.

- **`script eval` gotcha**: eval wraps code in a class named `Script`, which shadows the game's `Script` service locator. Use `FindAnyObjectByType<T>()` in eval code.
  Reusable eval scripts live in `Tools/Stress/`. `Narrator.gameInitialized` is never set, so wait for `!PlayerBehaviour.gamePaused` instead.
- **Don't edit `Assets/` scripts during a play session**: the recompile reloads the domain and breaks the run. Stop play mode first.
- Real scenes: `Assets/Scenes/TitleScene.unity` (index 0) and `Assets/Scenes/GameScene.unity` (index 1). Others are sandboxes or vendor demos.

## Workflow

- **Backlog = GitHub Issues** on `JustinLycklama/Escape-From-Io`, through `gh`. Labels: a type (`bug`, `feature`, `tech-debt`, `tooling`, `docs`),
  plus an `area:*` label (`tasks`, `pathfinding`, `map`, `units-buildings`, `ui`, `art-assets`) and `needs-repro` for unconfirmed bugs.
  Templates are in `.github/ISSUE_TEMPLATE/`.
- **Starting a session**: `git status` / `git log -5`, then `gh issue list` to see what's open. For a specific ticket, `gh issue view <n> --comments`.
- **Doing a ticket**: branch `<n>-short-name` off `master`, commit with `Fixes #<n>`, verify in the editor (above), then merge or open a PR into `master`.
  Record findings as issue comments, so the next session doesn't repeat the investigation.
- **New ideas or bugs found mid-task**: open an issue rather than fixing them in passing, unless they're tiny and directly related.
- `master` is the only long-lived branch. `legacy-mobile-wip` is the pre-revival tip, kept for reference.
- When a system's behaviour changes, update ARCHITECTURE.md in the same change.

## What's ours vs vendor

First-party code lives only in: `Assets/Game Management/`, `Assets/Game Objects/` (`Units/`, `Buildings/`, the top-level `.cs` files,
`Voxel Ships/RandomShipGenerator.cs`, `Voxel Ships/StationShip.cs`, `L3D_Assets/EarthElementalController.cs`), `Assets/Map Generation/`,
`Assets/PathFinding/`, `Assets/Math/` and `Assets/UI/` (except `PieChart/`, `SciFi UI Pings VFX/`, `Assets/Icons/`).
Everything else in `Assets/` is asset-store/vendor content: **don't modify it, and exclude it from searches and reviews.**

## Conventions in this codebase

- **Find managers with `Script.Get<T>()`** (Constants.cs), not `FindObjectOfType`. A new manager needs a `Script` entry, an `allScripts` entry and a Unity tag,
  otherwise `Get` silently returns null.
- **Observer pattern**: subscribers call `RegisterFor…(this)` and implement a `…Delegate` interface. Every Register needs a matching `End…` in `OnDestroy`.
- **Blueprints**: new units and buildings are `static Blueprint` fields on `Unit.Blueprint` / `Building.Blueprint`, with cost, a `Resources/` prefab path,
  an icon name and an optional placement predicate. The prefab must exist at that path.
- **Work happens through tasks**: gameplay actions create `MasterGameTask`s (made of `GameTask` steps) and `TaskQueueManager.QueueTask` them.
  Never drive a unit directly.
- **Respect pause**: coroutines check `playerBehaviour.gamePaused` and timers go through `TimeManager.AddNewTimer`.
- **Coordinates**: be explicit about which space a value is in (`LayoutCoordinate` / `MapCoordinate` / `PathGridCoordinate` / `WorldPosition`) and use the
  conversion helpers in `MapStructs.cs` / `MapsManager`.
- **Tutorial hooks**: gameplay code calls `TutorialManager.sharedInstance.Fire(TutorialTrigger.X)`. Keep these when refactoring.
- Style: K&R braces on the same line, `camelCase` fields, `PascalCase` methods, interfaces named `…Delegate` without an `I` prefix. Match the surrounding code.

## Gotchas

- Static state persists across scene loads (task counter, `UnitManager.unitCount`, singletons). Reset it explicitly if you add more.
- `Resources.Load` paths and Unity tags are stringly-typed. Renaming a prefab or tag breaks things at runtime, not at compile time.
- Task assignment was reported to stall in v0.2. A watchdog in `Narrator.CheckForTaskQueueManager` restarts it. See ARCHITECTURE.md → Known issues and the GitHub issue before touching `TaskQueueManager`.
- No `.obj` models were ever committed: a past global gitignore excluded them. Unity deletes their orphaned `.meta` files on open. **Don't commit those deletions**,
  because the metas preserve GUIDs for when the asset packs are reimported. Missing in-game: the Shuttle Frame mesh (Voxel StarForce pack) and `Buildings/arrow.obj` (Sensor Tower pointer).
- Firebase was removed. `FirebaseManager` is now a local PlayerPrefs leaderboard.
- `docs/` is the GitHub Pages site, not developer docs.
